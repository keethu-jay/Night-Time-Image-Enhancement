# Night-Time Image Enhancement

This project turns nighttime images into plausible daytime versions. We first tried classic image enhancement methods and measured how close they got to the real day image (MSE). Those methods did not give a good MSE. We then trained a CycleGAN for three rounds and used the best checkpoints to get much better MSE and visual quality.

## What Was Accomplished (Summary)

1. **Traditional enhancement baseline**  
   We ran several standard techniques (HSV adjustment, denoising, gamma correction, CLAHE, single- and multi-scale retinex) on night images and computed MSE against the paired day image. The script that builds the comparison grid and reports MSE for each method is under `scripts/preprocessing/`. Result: none of these gave a low enough MSE to match a real day look.

2. **CycleGAN training (three rounds)**  
   We switched to learning a night-to-day mapping with CycleGAN. Training was done in three rounds (often on a virtual GPU). Round 1 established a baseline; round 2 and 3 refined it. Best checkpoints by MSE, SSIM, and identity loss were identified by sweeping epochs.

3. **Metrics and reporting**  
   We added scripts to compute channel-wise MSE and SSIM, build verification images (night | real day | fake day), run batch inference on 220 night and 220 day images, and produce leaderboards and histograms. All of this is used to compare models and report results.

4. **Artifacts for the midterm**  
   The repo contains scripts to generate progression videos, the preprocessing grid with MSE per method, model selection tables, batch leaderboards, and individual histograms. Outputs are written to `important_metrics/` and related folders so you can plug them into slides or reports.

## Repository Structure (Where to Find Things)

All paths are relative to the project root.

- **`scripts/`** – All runnable scripts, grouped by purpose. Run them from the project root (e.g. `python scripts/metrics/calculate_final_grade.py`).
  - **`scripts/preprocessing/`** – Traditional enhancement and comparison. Builds the 7-panel grid (Night, HSV, Denoised, Gamma, CLAHE, Single Scale, Multi Scale) with MSE per panel vs the day image.
  - **`scripts/training/`** – Training-related: epoch sweep, loss log summary, training history, and plots of loss metrics (e.g. cycle_A, idt_A) across rounds.
  - **`scripts/inference/`** – Running the trained model: batch inference on 220+220 images, single-image runs, and progression videos from round 3. Also the inference how-to: `RUN_INFERENCE.md`.
  - **`scripts/metrics/`** – Computing and comparing metrics: **run_grading.py** (professor/TA: your own images through best MSE/SSIM/identity models), final grade (MSE/SSIM), batch analyzer (leaderboard), results dashboard, and report generation from loss logs.
  - **`scripts/visualization/`** – Building figures and videos: important_metrics folder (best MSE/SSIM/Idt images), batch and progression videos, histograms, and stacked verification images.

- **`important_metrics/`** – Curated outputs for reporting: best fake-day images, verification side-by-sides, preprocessing grid with MSE, model selection table, batch leaderboard CSV, histograms, and progression/batch videos (in `important_metrics/videos/`).

- **`paper_figures/`** – Generated by `scripts/visualization/generate_paper_figures.py`: Figure 1–6 (architecture, loss gallery, Round 2 vs 3, histograms, adversarial gap, traditional vs GAN) and Table 1 (peak performance) in one place for the paper.

- **`checkpoints/`** – Saved model weights and training logs.
  - **`checkpoints/round1/`**, **`round2/`**, **`round3/`** – Weights (e.g. `*_net_G_A.pth`) for each training round.
  - **`checkpoints/loss_logs/`** – Loss logs (e.g. `loss_log_round1.csv`, `loss_log.txt` for round 3). Used by training and visualization scripts.
  - **`checkpoints/model_best_mse/`**, **`model_best_ssim/`**, **`model_best_idt/`** – Copies of the best epochs used for batch inference and metrics.

- **`results/`** – Inference outputs. One folder per run (e.g. `results/round2/test_55/`, `results/model_best_mse/test_55/`). Each contains an `images/` subfolder with `*_fake.png` and HTML indices.

- **`datasets/`** – Data used for training and testing.
  - **`datasets/night2day/`** – Standard CycleGAN layout: `trainA`/`trainB` (night/day for training), `testA`/`testB` (night/day for testing). Used for training and for small-scale tests.
  - **`datasets/large_test/`** – Optional: `testA` (220 night images), `testB` (220 day images) for batch inference and leaderboard metrics.

- **`src/`** – CycleGAN (pix2pix) code: training, test, models, options. Training and inference are run from here (or via the scripts that call `src/test.py`).

- **`night-to-day-translation/`** – Data preparation only: scripts and seed images to build the night2day dataset (e.g. professor pair augmentation, Dark Zurich prep). See `night-to-day-translation/README.md`.

- **`docs/`** – Technical notes and step-by-step guides (e.g. batch inference and videos for the midterm).

## Steps Taken to Improve MSE

1. **Baseline: traditional methods**  
   We implemented and compared HSV, denoising, gamma, CLAHE, single-scale retinex, and multi-scale retinex. Each result was compared to the paired day image with MSE. The grid and MSE values are produced by `scripts/preprocessing/preprocessing_grid_with_mse.py`. These methods improved visibility but did not achieve a good MSE relative to the real day image.

2. **Round 1: initial CycleGAN training**  
   We trained CycleGAN on the night2day dataset to learn a direct night-to-day mapping. This round established that a learned model could do better than the traditional pipeline.

3. **Round 2: refinement and best-MSE epoch**  
   We continued training from round 1 weights. We swept epochs and selected the checkpoint with the lowest channel-wise MSE (e.g. round2 epoch 55) and used it for verification and batch runs. This round is the main source of “best MSE” and “best SSIM” models.

4. **Round 3: further training**  
   A third round was run for more epochs. Loss logs and optional progression videos (e.g. single night image through round 3 epochs) are generated by scripts in `scripts/training/` and `scripts/visualization/`.

5. **Batch evaluation**  
   We ran the best-MSE, best-SSIM, and best-identity checkpoints on 220 night images (night-to-day) and 220 day images (identity). Scripts under `scripts/inference/` and `scripts/metrics/` produce the leaderboard and CSVs in `important_metrics/`.

## Quick Start

- **Preprocessing grid (traditional methods + MSE)**  
  From project root:  
  `python scripts/preprocessing/preprocessing_grid_with_mse.py`  
  Optional: `--night`, `--day`, `--out`. Output: `important_metrics/preprocessing_grid_with_mse.png`.

- **Grading (professor/TA)**  
  Run your own night and optional day image through the best MSE, SSIM, and identity models and get a results table plus saved fake-day images:  
  `python scripts/metrics/run_grading.py --night path/to/your_night.jpg [--day path/to/your_day.jpg]`  
  Outputs go to `important_metrics/grading/` (or `--out-dir`). If you omit `--day`, inference still runs and fake images are saved; MSE/SSIM require `--day`. See the script docstring and `scripts/README.md` for details.

- **Final grade (MSE and SSIM on one pair)**  
  After running inference so that a fake day image exists (e.g. under `results/`):  
  `python scripts/metrics/calculate_final_grade.py`  
  Use `--real`, `--fake`, `--night`, `--out` to point to specific images.

- **Batch inference (220+220)**  
  Ensure `datasets/large_test/testA` and `testB` exist, then:  
  `python scripts/inference/run_batch_inference.py`  
  Then run `python scripts/metrics/batch_analyzer.py` to get the leaderboard and CSVs.

- **Paper figures and table**  
  One script generates all CVPR-style figures and Table 1:  
  `python scripts/visualization/generate_paper_figures.py`  
  Writes to `paper_figures/` (or `--out-dir`): Figure 1 (architecture), Table 1 (performance), Figure 2 (loss gallery), Figure 3 (Round 2 vs Round 3), Figure 4 (histograms N=440), Figure 5 (adversarial gap), Figure 6 (traditional vs CycleGAN). Use `--skip 3 5` to omit specific figures.

- **Loss metrics and plots**  
  Loss logs live in `checkpoints/loss_logs/`. To summarize and plot:  
  `python scripts/training/loss_log_summary.py`  
  `python scripts/training/plot_loss_metrics.py`  
  Outputs go to `important_metrics/`.

- **Inference how-to**  
  See `scripts/inference/RUN_INFERENCE.md` for exact commands to run Night→Day inference from `src/` and how the metrics scripts use the outputs.

## Requirements

See `requirements.txt`. Main dependencies: PyTorch, torchvision, numpy, Pillow, scikit-image, OpenCV, matplotlib. For GPU training, install PyTorch with CUDA from pytorch.org first.

## Data Prep

To build or extend the dataset locally, see `night-to-day-translation/README.md`. Training and heavy inference are intended to be run on a machine with a GPU (e.g. virtual GPU); this repo holds the code, data-prep scripts, and exported checkpoints and results.
